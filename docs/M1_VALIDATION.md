## 当前边界与后续接入

1. M1 提供人工闭环。自动解析、语义匹配、关联建议和真实 LangGraph 五步业务工作流属于 M2；当前不调用模型、不产生 embedding、不运行自动聚类。
2. 真实空间的坐标以节点创建时的稳定位置为基础；显示色不表示算法领域分类。语义布局、云团和自动配色按 M4/M5 推进。
3. 正文存于数据库；Markdown 导入支持普通正文及本产品的 JSON 值 front matter，不承诺通用 YAML 或外部文件夹同步。
4. 备份恢复只允许空知识库；备份不含模型配置和密钥。API 请求上限 16 MiB，前端恢复文件上限 15 MB，单篇正文上限 100 万字符；大库分页、分块备份后续再做。
5. 自动保存约 650 ms 防抖，切换前先保存；离线时保留当前编辑并提示，不提供关闭浏览器后的离线草稿恢复。多窗口冲突副本是用于手工合并的 JSON，不是完整库备份。
6. outbox 当前仅完成可靠事件送达和回执。后续生成向量或聚类需增加真实消费者，不能将已送达事件视为计算完成。
7. 当前为单用户本机服务；CI 增加了 M1 数据库集成检查，本次执行的是本机检查，尚未运行远端 CI。
