## 实现约定

- 默认打开真实知识空间；M0 演示单独保留在 `?benchmark=1`，不进入个人图谱。
- 草稿可为空；正式入图必须有标题并明确确认，可选择独立入图或手工指定关系。
- 正文、元数据、关系和历史保存于 PostgreSQL；布局坐标固定保存，漂浮只影响显示。
- 所有修改携带版本和操作 ID。旧版本返回冲突；操作重试返回原结果，不再次产生历史或事件。
- 删除节点时软删除关联，恢复时检查两端；手工删除的边不因节点恢复而自动复活。
- Markdown 导入支持本产品导出的 JSON 形式 front matter；纯 Markdown 也可导入。文件链接不自动建边。
- 完整恢复首版只允许导入空知识库，冲突时全部拒绝，避免静默覆盖；预览导入摘要后再确认。
- API Key 仅在后端加密保存，主密钥从环境注入。M1 提供配置保存及脱敏查看，实际模型连接测试和 AI 流程留到 M2。
- 真实内容编辑采用自动保存；切换或关闭前先完成保存，失败时保留本地编辑状态并提示。

## 验收用例

1. 新建并编辑草稿，刷新后恢复 Markdown、别名、标签与来源。
2. 明确确认入图；相同操作 ID 重试只产生一个节点、一条确认和一组事件。
3. 新建第二个节点，手工连线；对称关系反向重复被阻止，有向关系保留方向。
4. 修改正文或改名不丢关系，旧版本更新返回冲突；可查看历史并恢复到新版本。
5. 删除节点后进入回收站，活动图谱不再包含其关联；恢复有效关联，手工删除的边保持删除。
6. 搜索中文标题、别名、正文和标签，结果可打开正文并定位真实节点。
7. Markdown 导入生成草稿；完整备份可在空测试库恢复节点、边、草稿、版本和确认来源。
8. 密钥脱敏且不出现在日志、普通备份或前端响应；未配置主密钥时明确提示。
9. 关闭并重启应用后真实数据仍可读取；测试和 M0 场景保持隔离。
