# dayzero

Day Zero.

## Requirements

- Node.js >= 22

## Getting Started

```bash
# Install dependencies
npm install

# Run in development mode (with watch)
npm run dev

# Build
npm run build

# Run the built output
npm start
```

## Project Structure

```
dayzero/
├── src/          # TypeScript source code
│   └── index.ts  # Entry point
├── dist/         # Compiled output (git-ignored)
├── package.json
└── tsconfig.json
```
